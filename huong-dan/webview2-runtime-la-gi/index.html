WebView2 Runtime là gì? Có cần cài không?

WebView2 giúp ứng dụng Windows nhúng trang web bằng bộ dựng hình Microsoft Edge. Pip dùng runtime này thay vì đóng gói riêng một engine Chromium.

Cập nhật 16/10/2026 · Hướng dẫn của Pip Browser

Minh họa WebView2 giúp ứng dụng Windows hiển thị nội dung web.

WebView2 là thành phần cho phép ứng dụng Windows hiển thị nội dung web bằng công nghệ HTML, CSS và JavaScript. Microsoft Edge cung cấp engine dựng trang; ứng dụng Windows nhúng một điều khiển WebView2 bên trong cửa sổ của mình. Vì thế, ứng dụng có thể kết hợp giao diện web với chức năng native của Windows.

WebView2 là gì?

WebView2 là thành phần giúp ứng dụng Windows nhúng nội dung web bằng engine Microsoft Edge.

Microsoft Edge WebView2 Runtime là gì, khác Microsoft Edge thế nào?

Microsoft Edge là ứng dụng trình duyệt mà người dùng mở trực tiếp. WebView2 Runtime là thành phần chạy phía sau để ứng dụng khác nhúng nội dung web. Cả hai dùng công nghệ dựng hình của Microsoft Edge nhưng có mục đích và cách dùng khác nhau; xóa hoặc cài Edge không nên được xem là cách thay thế tùy ý cho WebView2 Runtime.

Vì sao Pip dùng WebView2?

Pip là giao diện trình duyệt Windows viết bằng Rust và WebView2 cung cấp engine hiển thị website. Khi dùng chế độ Evergreen, nhiều ứng dụng WebView2 trên cùng máy có thể dùng chung một bản Runtime; Microsoft nêu đây là cách tiết kiệm dung lượng đĩa. Runtime được cập nhật độc lập qua cơ chế Microsoft, còn phiên bản ứng dụng Pip vẫn được phát hành riêng. Dùng chung runtime không có nghĩa Pip nhẹ hơn mọi trình duyệt về RAM hoặc mọi website chạy nhanh hơn.

WebView2 cho Windows 10 và Windows 11

Microsoft cho biết Evergreen Runtime có sẵn trên Windows 11 đủ điều kiện và đã được cài trên nhiều thiết bị trước đó, nhưng một số máy vẫn thiếu runtime. Pip hỗ trợ Windows 10/11 64-bit. Khi tìm WebView2 cho Windows 10 hoặc WebView2 cho Windows 11, hãy kiểm tra runtime bằng bộ cài Pip hoặc tải trực tiếp từ Microsoft. Bộ cài Pip kiểm tra thành phần cần thiết; nếu chưa có, ứng dụng sẽ yêu cầu tải bộ cài WebView2 chính thức của Microsoft trước khi tiếp tục. Hãy dùng đúng lời nhắc trong bộ cài hoặc tải từ trang Microsoft, không lấy runtime từ trang chia sẻ không rõ nguồn.

Cách cài WebView2 Runtime nếu Pip báo thiếu

  1. Đảm bảo Windows được cập nhật và kết nối Internet ổn định.
  2. Chạy bộ cài Evergreen WebView2 Runtime từ trang Microsoft chính thức, sau đó mở lại Pip Setup.
  3. Nếu máy do cơ quan quản lý, hỏi quản trị viên trước khi cài thành phần hệ thống.
  4. Nếu lỗi vẫn còn, ghi lại thông báo cụ thể và phiên bản Windows để gửi hỗ trợ; đừng xóa thư mục Runtime thủ công.

Điều cần nhớ: Pip cần WebView2 để hiển thị các website. Runtime dùng chung có thể giảm dung lượng bị lặp trên đĩa, nhưng website vẫn chạy trên engine Edge và dùng tài nguyên tùy theo nội dung.
