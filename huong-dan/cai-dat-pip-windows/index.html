Cách tải và cài Pip Browser trên Windows 10/11

Tải bộ cài x64 trực tiếp từ website Pip, kiểm tra WebView2 và xác minh SHA-256 nếu muốn đối chiếu tệp tải.

Cập nhật 23/10/2026 · Hướng dẫn của Pip Browser

Minh họa Pip bên cửa sổ cài đặt và bước kiểm tra tệp tải.

Cách tải Pip Browser: Nhấn nút tải trên website chính thức để tải trực tiếp bộ cài x64 mới nhất cho Windows 10/11. Tránh tải từ trang bên thứ ba vì tệp ở đó có thể đã cũ hoặc bị thay đổi.

Đang dùng bản Pip cũ? Tải bộ cài mới nhất tại nút trên, đóng mọi cửa sổ Pip rồi chạy bộ cài để cập nhật. Dữ liệu hồ sơ và lịch sử duyệt web được giữ lại.

Cài Pip Browser trên Windows 11 (và Windows 10)

  1. Mở website Pip rồi nhấn nút tải để nhận trực tiếp bộ cài mới nhất.
  2. Tải tệp PipSetup.exe. Mở ghi chú phát hành chính thức ↗ để xem phiên bản và các thay đổi trước khi cài.
  3. Nếu Pip đang mở, đóng tất cả cửa sổ Pip trước khi cập nhật; bộ cài sẽ thay ứng dụng và giữ lại dữ liệu hồ sơ.
  4. Nếu muốn kiểm tra tệp, tải SHA256SUMS.txt từ liên kết mã SHA-256 trên website và làm theo hướng dẫn bên dưới.
  5. Mở bộ cài. Pip được cài riêng cho tài khoản Windows hiện tại. Nếu WebView2 Runtime chưa có, bộ cài sẽ đề nghị mở bộ cài Runtime chính thức của Microsoft.
  6. Sau khi hoàn tất, mở Pip từ shortcut hoặc Start Menu.

Cách kiểm tra SHA-256 file cài Windows

Tải SHA256SUMS.txt của bản mới nhất ↗

Mã SHA-256 là giá trị tính từ nội dung tệp. So sánh toàn bộ chuỗi với tên tệp tương ứng trong SHA256SUMS.txt lấy từ cùng trang phát hành. Mở PowerShell và chạy lệnh sau:

Get-FileHash -LiteralPath "$env:USERPROFILE\Downloads\PipSetup.exe" -Algorithm SHA256

Lệnh trên giả định tệp nằm trong thư mục Downloads mặc định của Windows. Nếu bạn lưu ở nơi khác, thay đường dẫn bằng vị trí thực tế của PipSetup.exe. Kết quả phải dùng thuật toán SHA256 và có chuỗi hash giống dòng của bộ cài trong manifest. Nếu hai mã không trùng, xóa tệp đó và tải lại từ trang chính thức; không chạy bộ cài chưa xác minh. Hash giúp phát hiện tệp không khớp với manifest; để kiểm tra nguồn tin cậy, hãy tải cả tệp lẫn manifest từ các nút tải chính thức của Pip.

Microsoft mô tả Get-FileHash là lệnh tính hash cho tệp; SHA256 là thuật toán mặc định nếu không chỉ định thuật toán khác.

Xác minh nguồn dựng của GitHub (tùy chọn)

Các tệp trong bản phát hành GitHub có artifact attestation gắn với quy trình dựng của dự án. Nếu đã cài GitHub CLI, trước tiên hãy đăng nhập một lần bằng lệnh sau rồi hoàn tất xác thực trong trình duyệt:

gh auth login

Sau khi đăng nhập, chạy lệnh này để kiểm tra bộ cài đã tải có khớp với bằng chứng phát hành của repo Pip:

gh release verify-asset "$env:USERPROFILE\Downloads\PipSetup.exe" --repo giangocquoc-art/pip-browser

Lệnh thành công xác minh digest của tệp với attestation của GitHub Release; đây là bước kiểm tra nguồn dựng nâng cao. Xem cách lệnh hoạt động trên GitHub CLI ↗. Artifact attestation không phải chữ ký Authenticode nên không tự gỡ cảnh báo SmartScreen.

Windows SmartScreen cảnh báo Pip Browser

Bộ cài Pip hiện chưa được ký số. Windows SmartScreen có thể cảnh báo ứng dụng chưa nhận diện khi bạn mở tệp tải từ Internet. Cảnh báo không tự chứng minh tệp là mã độc, nhưng cũng không nên bỏ qua. Kiểm tra tên miền tải của Pip, tên tệp và mã SHA-256 trước khi quyết định có tiếp tục hay không. Nếu chưa chắc nguồn gốc, hủy cài đặt và tải lại từ trang chính thức; không tắt SmartScreen toàn hệ thống để cài một ứng dụng.

WebView2 Runtime

Pip dùng Microsoft Edge WebView2 Runtime để hiển thị website. Nhiều máy Windows đã có runtime; nếu máy thiếu, tiến trình cài đặt Pip yêu cầu tải bộ cài Microsoft. Xem thêm WebView2 Runtime là gì nếu muốn hiểu vì sao thành phần này cần có.

Yêu cầu hiện tại: Windows 10/11 x64, kết nối mạng để tải bộ cài và WebView2 nếu thiếu. Thông tin phiên bản, bộ cài và mã SHA-256 được phân phối qua website Pip.
