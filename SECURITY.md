# Security Policy / Chính sách bảo mật

## Supported releases / Phiên bản được hỗ trợ

Security fixes are made against the latest public Pip release. Please update to the latest version before reporting an issue when possible.

Các bản sửa lỗi bảo mật được áp dụng cho bản Pip công khai mới nhất. Nếu có thể, hãy cập nhật Pip trước khi gửi báo cáo.

## Reporting a vulnerability / Báo cáo lỗ hổng

Please do not post exploit details, proof-of-concept code, private browsing data, or personal information in a public issue.

Không đăng chi tiết khai thác, mã thử nghiệm, dữ liệu duyệt web riêng tư hoặc thông tin cá nhân trong issue công khai.

Use GitHub's private vulnerability reporting from the repository's **Security** tab when that option is available. If GitHub does not show a private reporting option, open a public issue with only a brief request for a private reporting channel; do not include technical details until the maintainer provides one.

Khi GitHub cung cấp tính năng báo cáo riêng tư trong thẻ **Security**, hãy dùng tính năng đó. Nếu không thấy lựa chọn báo cáo riêng tư, chỉ mở issue công khai để xin kênh liên hệ riêng; không gửi chi tiết kỹ thuật cho đến khi người duy trì cung cấp kênh an toàn.

Include the affected Pip version, Windows version, steps to reproduce, and the impact you observed. Remove account names, URLs containing tokens, cookies, and other private data from logs or screenshots.

Hãy ghi phiên bản Pip, phiên bản Windows, các bước tái hiện và ảnh hưởng quan sát được. Xóa tên tài khoản, URL chứa token, cookie và dữ liệu riêng tư khỏi log hoặc ảnh chụp màn hình.

## Scope / Phạm vi

This policy covers the Pip application, its installer, and release files published by the Pip project. Microsoft Edge WebView2 and third-party libraries are maintained by their respective publishers; reports affecting those components should also be sent to the relevant upstream security contact.

Chính sách này áp dụng cho ứng dụng Pip, bộ cài và các tệp phát hành do dự án Pip công bố. Microsoft Edge WebView2 và thư viện bên thứ ba do nhà phát hành tương ứng bảo trì; hãy gửi báo cáo liên quan đến các thành phần đó cho nhóm bảo mật của họ.
